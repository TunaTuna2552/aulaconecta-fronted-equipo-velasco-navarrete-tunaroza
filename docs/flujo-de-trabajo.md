## Registro de comandos

1. git commit ¿Qué nodo nuevo apareció y dónde quedó apuntando la rama?
- El nuevo nodo que aparecio fue el c2y c3, la rama quedo apuntando al c3

2. git branch ¿Qué se creó y sobre qué commit quedó ubicado?
- Se creo una rama llamada 'bugFix' y quedo ubicada sobre el c2

3. git checkout ¿Qué cambió al moverse a otra rama?
- El asterisco se movió a la rama bugFix, indicando que ahora estaba trabajando sobre esa rama. 

4. git merge ¿Qué historias de trabajo quedaron integradas?
- Se unieron la rama 'bugFix' y 'main', quedando integradas
